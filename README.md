# ⌨️ গ্লাস কীবোর্ড

ডার্ক গ্লাস-ইফেক্টের Android কীবোর্ড — **অভ্র • প্রভাত / জাতীয় • हिन्दी • English** একসাথে।

## 🛠️ যা দিয়ে তৈরি
- 🟣 Kotlin + Android SDK (`InputMethodService`)
- 🧱 Gradle + GitHub Actions
- 🎙️ Android `SpeechRecognizer` (ভয়েস টাইপিং)
- 😊 Android ICU (ইমোজি নাম ও সার্চ)

## ✨ ফিচার
- ↔️ স্পেসবার স্লাইডে মসৃণ ভাষা বদল: English → অভ্র → প্রভাত (বা জাতীয়) → হিন্দি
- 🇮🇳 হিন্দি ফোনেটিক (রোমান → দেবনাগরী), দেবনাগরী সংখ্যা, যুক্তাক্ষর, নুক্তা; অপশনে চালু/বন্ধ
- 🔠 অভ্র ফোনেটিক (রেফারেন্স চার্ট অনুযায়ী: ঞ্জ, ঙ্ক, ণ্ড, ষ্ণ, জ্ঞ, ৎ = t``, ঃ = :), 🅿️ প্রভাত (লং-প্রেসে র-ফলা, রেফ, ৎ, য-ফলা…) ও 🇧🇩 জাতীয় লেআউট
- ⇧ শিফট একবার চাপলেই কাজ করে (বাংলায়)
- ⊞ ওপরের বাটনে 📋 ক্লিপবোর্ড, 🔢 নাম্বার, ⚙ সেটিংস; 🎤 ভয়েস সবসময় থাকে
- 💡 শব্দ সাজেশন ও পরের শব্দের অনুমান (অফলাইন, নিজে শেখে)
- 😊 রেফারেন্স-স্টাইল ইমোজি প্যানেল: সব ইমোজি + ♡ ★ ✿ চিহ্ন, সার্চ, স্কিন টোন
- ✂️ x / c / v চেপে ধরলে কাট / কপি / পেস্ট, বার্তা সাজেশন বারের জায়গাতেই দেখায়
- 🎨 ১৯টি থিম + 🖌️ কাস্টমাইজ (প্রতিটি অংশের রঙ নিজের মতো)
- 📖 অ্যাপের ভেতরেই পূর্ণ ব্যবহার গাইড
- 🔡 কী চাপলে তীরওয়ালা বুদবুদ পপ-আপ; লং-প্রেসে বিকল্প অক্ষর পপ-আপে দেখে ছাড়লে বসে
- 🗂️ ক্লিপবোর্ড ইতিহাস ও শেখা শব্দ অ্যাপের ভেতরে দেখা, এডিট, যোগ ও মোছা যায়
- 🎯 মিস-টাচ কমানোর স্মার্ট টাচ সিস্টেম
